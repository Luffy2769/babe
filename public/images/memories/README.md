# Memory photos

Drop the photos for the "Open When You Miss Me" carousel here, then point
`MEMORIES` in `src/config.ts` at them:

    01.jpg   02.jpg   03.jpg   04.jpg

- **Portrait crops look best** — the carousel frame is 4:5.
- **Resize before committing.** ~1200px on the long edge is plenty; full-size
  phone photos will make the page crawl on mobile data.
- Any missing file falls back to a labelled neon placeholder, so you can ship
  the page before you've finished picking pictures.
- Add or remove entries freely — the carousel and its dots follow the array
  length.
